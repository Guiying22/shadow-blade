# 影刃 · SHADOW BLADE

一个无需安装依赖的像素风浏览器动作小游戏。

在月下庭院中迎战三波妖潮：看准红刃预警，在攻击落下的瞬间闪避，再用强化后的下一刀扭转战局。

**在线试玩：<https://guiying22.github.io/shadow-blade/>**

## 玩法

- **WASD / 方向键**：移动
- **J**：攻击
- **K / 空格**：闪避（短暂无敌）
- **P**：暂停
- **R**：重新开始

## 核心机制

- 游戏共 **3 波**：第 1 波击杀 10 只小怪，第 2 波击杀 15 只，第 3 波鬼武者与不断刷新的小怪同场，击败鬼武者即获胜。
- 每波结束时回复最多 30 点生命，并在屏幕中央提示波次进度。
- 小怪会在地图随机位置刷新，共有四种：
  - **赤鬼**：追击玩家，抬手后近身劈砍，并带有碰撞伤害。
  - **疾影**：血量很低（10 点），移动极快，只有碰撞伤害。
  - **咒术师**：与玩家保持距离，每秒发射一枚远程射弹，射弹存活 3.5 秒。
  - **瞳炮**：不会移动，发射长激光；开火前 0.3 秒会用细红线标出激光轨迹。
- 敌人攻击前会显示红色扇形预警。
- 在红刃命中的瞬间闪避，会触发 **完美闪避**。
- 完美闪避后 5 秒内，下一次攻击命中时随机触发：
  - **暴击**：造成 1.5 倍伤害
  - **眩晕**：敌人失去行动能力 1.6 秒
- 鬼武者生命值低于 45% 时会进入激怒状态，攻击速度提升。
- 战斗结束后会统计战斗时间、完美闪避次数、暴击次数、眩晕次数、击杀小怪数与总伤害。

## 运行

直接用浏览器打开 `index.html` 即可，无需安装或构建。

也可以启动一个本地静态服务器：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

推荐使用桌面浏览器和键盘游玩。

## 技术

- HTML5 Canvas 像素渲染
- 原生 JavaScript（无框架、无外部素材）
- Web Audio API 合成音效
- 响应式界面
